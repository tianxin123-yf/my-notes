实验三.SIFT 特征匹配
一、实验目的
1.掌握图像拼接的基本原理与完整流程，理解如何把两张有重叠区域的图片拼成一张全景图；
2.学会使用 OpenCV 的 SIFT 特征检测算法提取图像关键点与描述符；
3.理解 FLANN 特征匹配与 Lowe 比率测试筛选优质匹配点的方法；
4.理解单应矩阵（Homography）的物理意义，掌握用 RANSAC 稳健估计单应矩阵的方法；
5.掌握通过透视变换（warpPerspective）和平移把图像投影到同一坐标系实现拼接的完整实现，并能用 Python 独立完成。
二．实验过程
1.环境准备： 安装 opencv-contrib-python 和 numpy；准备两张有重叠区域的图片 a.jpg、b.jpg。





2.读取与灰度化：读入两张图，cvtColor 转为灰度图，供 SIFT 使用；


3.特征提取：用 sift.detectAndCompute 提取两图各自的关键点和描述符；

4.特征匹配：用 FlannBasedMatcher.knnMatch 每个点找 2 个最近邻；
5.筛选匹配：用 Lowe 比率测试（m.distance < 0.7 * n.distance）保留区分度高、可信的匹配点，去掉误匹配；
6.求单应矩阵：用 findHomography(..., RANSAC, 5.0) 从匹配点对中稳健地拟合两图间的变换关系 H；

7.透视变换拼接：把 b 图四个角点按 H 变换，计算拼接画布尺寸，加平移矩阵避免负坐标，用 warpPerspective 把 b 图变换到 a 图坐标系；

8.融合与输出：把 a 图贴到对应位置，imshow 显示匹配点和拼接结果，imwrite 保存 stitched_result.jpg。


三．运行结果
运行成功，弹出匹配点可视化窗口和拼接结果窗口，两张重叠图片被正确拼接成一张完整全景图并保存。


四．实验中遇到的问题及解决方式
窗口显示过大 拼接图尺寸大，弹出窗口占满屏幕。解决：显示前用 cv2.resize 按比例缩放，只影响显示不影响保存原图。
五．实验心得
通过本实验，我完整掌握了图像拼接的核心思路：提取特征，匹配，求变换，拼接，理解了它不是简单把两张图并排，而是要通过单应矩阵把两图变换到统一坐标系再融合，也深刻体会到 SIFT 特征的优越性，对旋转、尺度变化稳定，是图像配准的基础。# my-notes
